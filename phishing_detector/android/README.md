# نسخة الأندرويد — كاشف روابط التصيّد

تطبيق أندرويد يكتشف روابط التصيّد **داخل الجهاز بالكامل (offline)** — لا يحتاج
إنترنت ولا سيرفر، ولا يطلب أي صلاحيات، ولا يُرسل أي رابط لأي جهة.

يستخدم **نفس خصائص المشروع البحثي** (26 خاصية) ونموذج **Logistic Regression**
مُصدَّر من بايثون (`export_model.py`) بدقّة **~95%**. تم التحقق أن الكشف في
الجوال **مطابق تماماً** لنتيجة بايثون (فرق الاحتمال = 0.0).

---

## خياران للأستاذ

### ✅ الخيار الأول: التطبيق الفوري (يشتغل حالاً، بدون تثبيت)
مجلد `webapp/` — يفتح على أي جوال/حاسوب مباشرة بدون أي إعداد:

1. انسخي مجلد `webapp` على القرص/الجوال.
2. افتحي `webapp/index.html` بأي متصفح (Chrome على الأندرويد).
3. الصقي الرابط واضغطي «افحص» — النتيجة فوراً، بدون إنترنت.

> يمكن «إضافته للشاشة الرئيسية» من قائمة المتصفح ليصبح مثل تطبيق حقيقي.

### 📱 الخيار الثاني: تطبيق أندرويد أصلي (ملف APK)
مجلد `PhishGuard/` — مشروع Android Studio كامل يبني ملف `.apk` قابل للتثبيت.

**البناء (يحتاج جهازاً فيه Android Studio واتصال إنترنت — لأن أدوات
Android SDK تُنزَّل من خوادم Google):**

```bash
# داخل مجلد PhishGuard
./gradlew assembleDebug
# الناتج:
# PhishGuard/app/build/outputs/apk/debug/app-debug.apk
```

أو من واجهة Android Studio: افتحي المجلد `PhishGuard` ثم
**Build ▸ Build APK(s)**.

ثم انسخي `app-debug.apk` على القرص، وعلى الجوال فعّلي «تثبيت من مصادر غير
معروفة» وثبّتيه.

> ملاحظة: لم نتمكن من بناء الـ APK في بيئة التطوير السحابية هذه لأن خوادم
> Google (لتنزيل Android SDK) محجوبة عنها. البناء يتم بسهولة على جهاز الأستاذ
> أو الطالبة عبر Android Studio بضغطة واحدة.

## بنية المشروع
```
android/
├── export_model.py      # يصدّر النموذج الخفيف من بايثون إلى model.json
├── model.json           # أوزان النموذج + قوائم الكلمات المشبوهة
├── webapp/              # التطبيق الفوري (HTML/JS) — يعمل offline
│   ├── index.html       # الواجهة (عربية RTL، تصميم موبايل)
│   ├── detector.js      # استخراج الخصائص + الاستدلال (منقول من features.py)
│   └── model.js         # النموذج مغلّف للتحميل بدون سيرفر
└── PhishGuard/          # مشروع أندرويد أصلي (Kotlin + Gradle)
    ├── app/src/main/
    │   ├── java/.../MainActivity.kt   # يحمّل الواجهة في WebView
    │   ├── assets/                    # نفس ملفات webapp مضمّنة بالتطبيق
    │   ├── AndroidManifest.xml        # بدون إذن إنترنت
    │   └── res/                       # السمة والأيقونة
    ├── build.gradle.kts / settings.gradle.kts
    └── gradlew                        # لبناء APK من سطر الأوامر
```

## كيف يعمل الكشف داخل الجوال
1. **استخراج الخصائص** (`detector.js`): يحوّل الرابط إلى 26 رقماً
   (الطول، عدد الرموز، وجود IP، كلمات الخداع، انتحال العلامات، النطاق المشبوه...).
2. **التحجيم** ثم **الاستدلال**: `z = Σ(الوزن × الخاصية) + الثابت` ثم `sigmoid(z)`.
3. القرار: احتمال ≥ 0.5 → تصيّد، مع عرض المؤشرات التي رُصدت.
