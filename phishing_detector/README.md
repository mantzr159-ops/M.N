# كاشف روابط التصيّد (Phishing URL Detector)

مشروع أمني **دفاعي** يكتشف روابط التصيّد الاحتيالية باستخدام تعلّم الآلة،
بالاعتماد على تحليل بنية الرابط (Lexical features) فقط — بدون فتح الرابط.

> **الغرض:** بحثي/تعليمي (كشف وحماية). المشروع لا يهاجم أي نظام ولا يتتبّع أي شخص.

## البنية
```
phishing_detector/
├── data/
│   ├── generate_dataset.py   # توليد بيانات واقعية (استبدليها ببيانات حقيقية لاحقاً)
│   └── urls.csv              # الناتج: url,label  (0=آمن، 1=تصيّد)
├── src/
│   ├── features.py          # استخراج ~27 خاصية من كل رابط  ← قلب المشروع
│   ├── train.py             # التدريب + التقييم + حفظ النموذج
│   ├── predict.py           # أداة سطر أوامر للكشف عن رابط
│   └── evaluate.py          # رسم مخططات التقييم (PNG)
├── model/                   # النموذج المدرّب + المقاييس (تُنشأ بعد التدريب)
├── figures/                 # مخططات (تُنشأ بعد evaluate)
└── requirements.txt
```

## التشغيل
```bash
pip install -r requirements.txt

# 1) توليد البيانات
python data/generate_dataset.py

# 2) التدريب والتقييم
python src/train.py

# 3) رسم المخططات
python src/evaluate.py

# 4) كشف رابط
python src/predict.py "http://instagram.secure-login.tk/verify"
python src/predict.py            # وضع تفاعلي
```

## كيف يعمل؟
1. **استخراج الخصائص:** كل رابط → متجه أرقام (الطول، عدد النقاط/الشرطات، وجود IP،
   كلمات خداع، انتحال علامة تجارية، إنتروبيا الاسم، نطاق علوي مشبوه...).
2. **التصنيف:** نموذج Random Forest يتعلّم من آلاف الأمثلة ويصنّف أي رابط جديد
   مع نسبة ثقة.

## تطويرات بحثية مقترحة (لمستوى الدكتوراه)
- استبدال البيانات المُولّدة ببيانات حقيقية (PhishTank, OpenPhish, Tranco).
- مقارنة خوارزميات (Random Forest / XGBoost / SVM / شبكات عصبية).
- إضافة خصائص قائمة على المحتوى (HTML/JS) وخصائص WHOIS/DNS.
- دراسة الهجمات المضادة (Adversarial phishing) ومقاومة النموذج لها.
- النشر كـ API أو إضافة متصفح.
