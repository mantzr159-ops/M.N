# متجر M.N — متجر إلكتروني عربي

متجر إلكتروني بسيط وسريع، يعمل في المتصفح مباشرة بدون أي تثبيت (HTML + CSS + JavaScript).

## المميزات
- واجهة عربية كاملة (RTL) بخط Tajawal، ومتجاوبة مع الجوال، وتدعم الوضع الداكن
- عرض المنتجات مع التصنيفات والبحث والترتيب (السعر / التقييم)
- نافذة تفاصيل المنتج مع اختيار الكمية
- سلة تسوق جانبية تُحفظ تلقائيًا في المتصفح (localStorage)
- حساب الشحن تلقائيًا (مجاني فوق 200 ر.س)
- نموذج إتمام الطلب مع التحقق من البيانات وصفحة تأكيد برقم الطلب
- **لوحة تحكم** (`admin.html`) لإدارة المنتجات والتصنيفات

## لوحة التحكم
افتح `admin.html` (يوجد رابط لها في أسفل المتجر). تتيح لك:
- إضافة منتج وتعديله ونسخه وحذفه: الاسم، التصنيف، السعر والسعر قبل الخصم، المخزون، التقييم، الوصف، وصورة أو رمز تعبيري
- تتبع المخزون: المنتج الذي نفدت كميته يظهر «غير متوفر» في المتجر، ولا يمكن طلب أكثر من الكمية المتاحة
- إضافة التصنيفات وإعادة تسميتها وحذفها
- تصدير نسخة احتياطية (JSON) واستيرادها، واستعادة البيانات الافتراضية

**مهم:** التعديلات تُحفظ في متصفحك فقط، والزوار يرون محتوى `products.js`. لنشر التعديلات للجميع: من تبويب «النسخ الاحتياطي» حمّل `products.js` واستبدل به الملف الموجود في المشروع.
اللوحة غير محمية بكلمة مرور. لا تعتبرها آمنة إلا إذا أضفت حماية من جهة الخادم.

## التشغيل
افتح ملف `index.html` في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## التخصيص
| الملف | الغرض |
|------|-------|
| `products.js` | المنتجات والتصنيفات الافتراضية (يمكن توليده من لوحة التحكم) |
| `admin.html` / `admin.js` / `admin.css` | لوحة التحكم |
| `app.js` | منطق المتجر (العملة، حد الشحن المجاني، رسوم الشحن في أعلى الملف) |
| `styles.css` | الألوان والتصميم (المتغيرات في `:root`) |

> ملاحظة: الطلبات حاليًا تُحفظ في المتصفح فقط. لربطها بخادم أو بوابة دفع، راجع الدالة `submitOrder` في `app.js`.
